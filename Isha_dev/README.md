#  EnviroScan - Week 1: Data Collection & Integration

##  Project Overview
EnviroScan is an environmental data analysis platform that combines pollution, weather, and location data for Indian cities. This Week 1 deliverable focuses on data collection, storage, and initial integration.

##  Week 1 Deliverables

### 1.  Data Collection Scripts
- Location Features Collector: Fetches geographical and infrastructure data
- Pollution Data Collector: Gathers air quality metrics
- Weather Data Collector: Collects meteorological data

### 2.  Data Storage
- Raw data stored in CSV format
- Structured directory organization
- Timestamped file versions

### 3.  Data Integration
- Combined dataset creation
- Feature engineering
- Missing value handling

##  APIs Used
- OpenAQ API: Pollution data (PM2.5, PM10, NO₂, CO, SO₂, O₃)
- OpenWeatherMap API: Weather data (temperature, humidity, wind speed, wind direction)
- OpenStreetMap (Overpass API): Location features (roads, industrial zones, dump sites, farmland)
