🌍 EnviroScan – AI-Powered Pollution Source Identifier
📌 Project Overview

EnviroScan is an AI-based system that identifies likely sources of air pollution using geospatial analytics and machine learning.

Traditional pollution monitoring systems only measure pollutant levels.
This system goes further — it predicts why pollution is occurring (vehicular, industrial, agricultural, natural, etc.).

🎯 Objectives

Predict pollution source (Vehicular / Industrial / Agricultural / Natural)

Generate geospatial heatmaps of pollution hotspots

Provide real-time alerts for high-risk zones

Support data-driven environmental decision making


Modules Implemented
✅ Module 1: Data Collection

Air Quality Data (PM2.5, PM10, NO₂, CO, SO₂, O₃) – OpenAQ API

Weather Data (Temperature, Humidity, Wind Speed, Wind Direction) – OpenWeatherMap

Spatial Features (Roads, Industrial Zones, Agricultural Fields, Dump Sites) – OSMnx

Stored in structured CSV format
